1. EXECUTIVE SUMMARY & MISSION
================================================================================
Retail investors in India often face unexplained broker deductions, delayed 
redemptions, unauthorized trades, mis-selling, and complex grievance portals 
(SEBI SCORES, SMART ODR, BSE/NSE Investor Services, Banking Ombudsman). 

NiveshRakshak transforms this chaotic, frustrating experience into a structured, 
actionable operating system. It never acts as a generic conversational chatbot:
every regulatory output is strictly anchored to statutory circulars, Master 
Directions, and investor charters from SEBI, NSE, BSE, AMFI, and RBI.

Core Value Proposition:
1. Grounded Regulatory Guidance: Zero hallucinated rules. If evidence is missing 
   from the verified knowledge base, the system explicitly states:
   "I could not find sufficient information in the verified knowledge base."
2. Document Forensic Audit: Uploads contract notes, ledgers, and statements to 
   extract charges, identify missing contract notes, and highlight violations.
3. Intelligent Evidence Checklist: Calculates evidence completeness percentage 
   before drafting complaints.
4. Formal Complaint Drafting & Quality Scoring: Generates structured legal-grade 
   complaints with a 0-100 Complaint Quality Score and instant branded PDF export.
5. Personalized Safety Score (0-100): Evaluates 6 key safety dimensions and 
   runs an adaptive learning loop with real-world scenarios.

2.2 TECHNOLOGY STACK
--------------------------------------------------------------------------------
- Frontend:
  * Framework: React 18 with Vite and TypeScript
  * Styling: Tailwind CSS (Fintech Slate/Navy Dark Palette)
  * Icons: Lucide React
  * State & Network: Native Fetch with centralized API service proxy
- Backend:
  * Runtime: Node.js 20 LTS

  * Authentication: JSON Web Tokens (JWT) + bcrypt password hashing
  * Document Generation: PDFKit (Vector layout, metadata stamps, signature blocks)
  * Database: MongoDB with Mongoose + resilient in-memory fallback
- AI Service:
  * Language & Runtime: Python 3.12 via Virtualenv (`ai-service/.venv`)
  * Web Framework: FastAPI + Uvicorn
  * Numerical & RAG Engine: NumPy, scikit-learn, rank-bm25, PyPDF2
  * Embeddings: Dense 256-dim feature vectorizer with domain term projection
  * Evaluation: Dedicated benchmark harness (`evaluator.py`)

2.3 DATA STORAGE & VECTOR STORE ARCHITECTURE
--------------------------------------------------------------------------------
1. Statutory Sources (`data/rag_data/`):
   Contains authoritative legal texts:
   - SEBI Investor Charter 2021
   - SEBI Master Circular on Grievance Redressal (SCORES 2.0 & SMART ODR)
   - NSE Master Circular on Trading & Settlement Rules (T+1, Contract Notes)
   - BSE Investor Services Cell & Arbitration Rules
   - AMFI Code of Conduct on Mutual Fund Redemptions & T+2 Payouts
   - RBI Integrated Ombudsman Scheme 2021
   - SEBI Advisory on Unregistered Finfluencers & Algorithmic Scams
   - SEBI KYC Master Direction & Demat Dormancy Rules
   - SEBI Prohibition of Fraudulent and Unfair Trade Practices (PFUTP)
   - SEBI Advisory on Unauthorized Algorithmic Trading & Social Media Frauds

2. Persistent Vector Index (`ai-service/rag_storage/`):
   - `knowledge_manifest.json`: Tracks SHA-256 hashes, file modification times, 
     chunk counts, and authorities to eliminate redundant re-indexing.
   - `chunks.json`: Stores 77 hierarchical chunks with source name, authority, 
     section, page, chunk id, and verified excerpts.
   - `embeddings.npy`: Binary NumPy matrix of dense normalized vectors.

2.4 MULTI-AGENT ORCHESTRATION ARCHITECTURE
--------------------------------------------------------------------------------
The system uses a specialized multi-agent design rather than a single monolith:
1. Orchestrator (`orchestrator.py`):
   Classifies incoming user intent into RIGHTS, GRIEVANCE, SCAM, DOCUMENT, 
   COMPLAINT, or LEARNING and routes to the appropriate specialist agent.
2. Rights Agent (`rights_agent.py`):
   Executes hybrid RAG retrieval, runs anti-hallucination checks, builds verified 
   citations with page numbers, and formulates structured legal rights advice.
3. Grievance Agent (`grievance_agent.py`):
   Extracts category, subcategory, financial impact, entity names, missing evidence, 
   statutory escalation tiers (Intermediary -> SCORES -> SMART ODR), and deadlines.
4. Scam Radar Agent (`scam_agent.py`):
   Scans messages, URLs, promises, and telegram handles for 10 high-risk patterns 
   (e.g., guaranteed returns, SEBI impersonation, unverified UPIs, APK downloads).
5. Document Forensic Agent (`document_agent.py`):
   Parses financial statements, contracts, and ledgers; extracts transactions; 
   flags unauthorized brokerage/charges against SEBI maximum statutory ceilings.
6. Complaint Agent (`complaint_agent.py`):
   Evaluates evidence completeness, drafts legal grievance petitions, calculates 
   the 0-100 Complaint Quality Score, and generates PDF export payloads.
7. Learning Academy Agent (`learning_agent.py`):
   Generates adaptive scenario-based quizzes, diagnoses weak dimensions, and 
   calculates the multi-dimensional Investor Safety Score (0-100).
8. Recommendation Agent (`recommendation_agent.py`):
   Analyzes all open grievances, documents, and quiz scores to output the 
   "Next Best Action" for the investor.

3.2 SUBSYSTEM 1: RIGHTS ASSISTANT (VERIFIED RAG CHAT)
--------------------------------------------------------------------------------
- Purpose: Provides instant, legal-grade answers to investor rights queries.
- Key Capabilities:
  * Strict grounding: Answers exclusively from ingested regulatory texts.
  * Verified Source Citations: Displays authority badge (SEBI, NSE, RBI, AMFI), 
    document title, section, page number, relevance score, and source excerpt.
  * Follow-up Suggestions & Next Actions: Directly offers one-click shortcuts 
    to analyze a document or draft a formal complaint.
  * Non-hallucinatory fallback: When an out-of-scope query is received, it 
    refuses to fabricate answers and directs to official helplines.

--------------------------------------------------------------------------------
3.3 SUBSYSTEM 2: GRIEVANCE INTELLIGENCE STUDIO & COMPLAINT DRAFTER
--------------------------------------------------------------------------------
- Purpose: Translates investor disputes into formal, structured legal filings.
- Key Capabilities:
  * Automated Classification: Maps dispute to 12 regulatory categories 
    (Unauthorized Charges, Mis-selling, Delayed Redemption, Non-receipt of funds, etc.).
  * Evidence Completeness Meter: Evaluates required documents (Contract note, 
    bank statement, broker email, ledger) and calculates an evidence completeness %.
  * Statutory Escalation Roadmap: Identifies exact regulatory paths:
    Tier 1: Broker / Intermediary Grievance Officer (21 days)
    Tier 2: Exchange / SEBI SCORES 2.0 Portal (21 days)
    Tier 3: SMART ODR Online Dispute Resolution / Conciliation / Arbitration
  * Complaint Drafter: Synthesizes subject, chronology, legal provisions, and 
    requested reliefs into a professional legal format.
  * Complaint Quality Score (0-100): Evaluates clarity, facts, amounts, 
    evidence attachments, and provides concrete improvement advice.
  * PDF Export Engine: Downloads a formatted, official PDF document.

--------------------------------------------------------------------------------
3.4 SUBSYSTEM 3: GRIEVANCE LIFECYCLE TRACKER
--------------------------------------------------------------------------------
- Purpose: Real-time visual tracking of submitted grievances.
- Key Capabilities:
  * Visual Stage Progression: SUBMITTED -> ACKNOWLEDGED -> UNDER_REVIEW -> 
    ESCALATED -> RESOLVED.
  * Dynamic Deadline Monitor: Calculates remaining calendar days before 
    investor is eligible to escalate to SEBI SCORES or SMART ODR.
  * Action History & Status Events: Timestamped log of communications, evidence 
    submissions, and intermediary replies.

--------------------------------------------------------------------------------
3.5 SUBSYSTEM 4: DOCUMENT FORENSIC AUDIT STUDIO
--------------------------------------------------------------------------------
- Purpose: Automated audit of financial statements, contract notes, and ledgers.
- Key Capabilities:
  * Upload Support: Ingests PDF statements, text ledgers, and transaction files.
  * Forensic Charge Detection: Scans every debit item; compares charges against 
    SEBI statutory maximums (e.g. max brokerage cap of 2.5%, turnover fees).
  * Missing Evidence Detection: Highlights unbilled turnover or missing 
    corresponding contract notes within mandatory 24-hour statutory windows.
  * Interactive Findings Panel: Grouped by Potential Issues, Detected Charges, 
    Key Dates, and Recommended Investor Remedies.

--------------------------------------------------------------------------------
3.6 SUBSYSTEM 5: SCAM & FRAUD SIGNAL RADAR
--------------------------------------------------------------------------------
- Purpose: Early warning risk analyzer for suspicious investment solicitations.
- Key Capabilities:
  * 10 High-Risk Signal Detectors:
    1. Guaranteed / Assured Return Claims (Violation of SEBI regulations)
    2. High-Pressure / Artificial Urgency Tactics ("Transfer within 1 hour")
    3. Unregistered Intermediaries / Fake SEBI Registration Numbers
    4. Personal UPI / Private Bank Accounts for Equity Investments
    5. Requests for Remote Screen Access Apps (AnyDesk, TeamViewer, RustDesk)
    6. Telegram / WhatsApp "VIP Institutional / Upper Circuit" Groups
    7. Unrealistic Profit Promises (e.g., 20-50% monthly returns)
    8. Demands for "Withdrawal Tax" or "Security Deposits" to release funds
    9. Unofficial APK Downloads or Fake Trading Portal Links
   10. Sharing of OTPs, Passwords, or Demat Credentials
  * Safe Harbor Disclaimers: Provides educational risk indicators without 
    making definitive criminal charges, advising investor verification steps.

--------------------------------------------------------------------------------
3.7 SUBSYSTEM 6: INVESTOR SAFETY ACADEMY & ADAPTIVE QUIZ
--------------------------------------------------------------------------------
- Purpose: Continuous investor education with personalized safety scoring.
- Key Capabilities:
  * 6-Dimension Safety Score (0-100):
    1. Investor Rights Awareness
    2. Grievance Redressal Mechanisms
    3. Scam & Fraud Detection
    4. KYC & Demat Account Hygiene
    5. Financial Document & Statement Auditing
    6. Digital Security & Operational Safety Habits
  * Adaptive Scenario-Based Quizzes: Real-world practical dilemmas (e.g., 
    broker demands verbal authorization, WhatsApp group offers IPO allocation).
  * Feedback & Learning Modules: Weak dimensions are identified and paired 
    with bite-sized remedial reading modules to improve investor safety score.

--------------------------------------------------------------------------------
3.8 SUBSYSTEM 7: STATUTORY RIGHTS LIBRARY
--------------------------------------------------------------------------------
- Purpose: Interactive, searchable catalog of investor rights in simple language.
- Key Capabilities:
  * Structure: Legal Provision -> Plain English Translation -> Real-World 
    Example Scenario -> Immediate Action You Can Take.
  * Multi-Domain Coverage: Trading & Brokerage, Mutual Funds, IPO & Demat, 
    Grievance Redressal, and Digital Privacy.

--------------------------------------------------------------------------------
3.9 SUBSYSTEM 8: RAG KNOWLEDGE BASE & EVALUATOR MONITOR
--------------------------------------------------------------------------------
- Purpose: Real-time observability and health dashboard for the RAG knowledge base.
- Key Capabilities:
  * Live Metrics: Document count, total indexed chunks, authorities represented,

  * Live Evaluator Suite: Real-time execution of the 7 golden test cases (TC01-TC07) 
    measuring Retrieval Relevance (100%), Citation Coverage (100%),

--------------------------------------------------------------------------------
3.10 SUBSYSTEM 9: TRUST & RESPONSIBLE AI CENTER
--------------------------------------------------------------------------------
- Purpose: Explains safety architecture, privacy protections, and ethics.

  * 100% Grounded Regulatory Advice: Strict prohibition on synthetic rules.

  * Zero Data Leaks: Sanitized processing, no credential logging, and right

5. HOW TO RUN THE APPLICATION (STEP-BY-STEP)
================================================================================

5.1 PREREQUISITES
--------------------------------------------------------------------------------
1. Node.js: Version 18.0+ or 20.0+ (Run `node -v` to verify)
2. Python: Version 3.10+ or 3.12+ (Run `python3 -v` to verify)
3. Package Managers: `npm` for frontend/backend, `pip` / `uv` for Python.
4. MongoDB (Optional): If MongoDB is running locally on port 27017, the backend 
   connects seamlessly. If MongoDB is absent, the backend automatically uses 
   its built-in resilient in-memory data store.

5.2 QUICK LAUNCH COMMANDS
--------------------------------------------------------------------------------
Open three separate terminal windows in the project root:

TERMINAL 1 (Python AI Microservice):
--------------------------------------------------------------------------------
cd ai-service
# Activate virtual environment
source .venv/bin/activate
# Start FastAPI on port 8000
uvicorn main:app --host 0.0.0.0 --port 8000 --reload

TERMINAL 2 (Node.js Backend Gateway):
--------------------------------------------------------------------------------
cd backend
# Start Express server on port 5001
node src/server.js

TERMINAL 3 (React Vite Frontend):
--------------------------------------------------------------------------------
cd frontend
# Start Vite development server on port 5173
npm run dev

Now open your browser and navigate to:
http://localhost:5173

All requests to `http://localhost:5173/api/*` are automatically proxied 
to the Node.js backend on `http://localhost:5001/api/*`, which in turn delegates 
AI intelligence tasks to `http://localhost:8000/*`.

5.3 RAG INGESTION & RE-INDEXING COMMANDS
--------------------------------------------------------------------------------
To ingest new official circulars, PDFs, or regulations:
1. Place the files into the appropriate folder under `/data/rag_data/`
   (e.g., `sebi/`, `nse/`, `bse/`, `amfi/`, `rbi/`).
2. Run the ingestion command from the project root:
   npm run rag:ingest
   (or from `ai-service`: `source .venv/bin/activate && python -m rag.ingest`)

To wipe the vector cache and force a complete re-indexing:
   npm run rag:reindex
   (or from `ai-service`: `python -m rag.ingest --force`)

6.1 AUTOMATED RAG BENCHMARK EVALUATION TESTING
--------------------------------------------------------------------------------

================================================================================
7. ANTI-HALLUCINATION & SECURITY GUARDRAILS
================================================================================
NiveshRakshak implements five non-negotiable security and trust guardrails:

1. Strict RAG Grounding Filter (`pipeline.py`):
   Every answer is constructed from retrieved context chunks. If the similarity 
   score fails the statistical relevance threshold, the system enforces the 
   statutory safe-harbor fallback. It never invents legal provisions.

2. Source Citation Transparency (`citation.py`):
   Every regulatory proposition is tied to authority, document title, section, 
   and page number. Users can expand citations to review the original legal text.

3. Human-in-the-Loop Complaint Drafter:
   The complaint draft is explicitly marked as "AI-Generated Draft — Review 
   Before Submission." The platform never automatically files complaints on 
   behalf of an investor without explicit review.

4. Zero PII & Credential Logging:
   Uploaded document text is processed in memory. Passwords, auth tokens, bank 
   account passwords, and personal financial credentials are never written 
   to server logs.

5. Educational Risk Terminology:
   The Scam Radar utilizes safe harbor framing: "Potential Risk Signals 
   Detected" rather than making unverified criminal accusations.

8. TROUBLESHOOTING & COMMON SCENARIOS
================================================================================

Q1: What if the AI service fails to start with "Address already in use"?
A1: A previous process may be occupying port 8000. Run:
    lsof -i :8000
    kill -9 <PID>
    Then restart the service with `uvicorn main:app --host 0.0.0.0 --port 8000`

Q2: What if MongoDB is not running on my machine?
A2: The Node.js backend automatically detects connection unavailability and 
    activates its in-memory storage driver. The app functions with 100% of 
    features enabled without requiring a MongoDB daemon.

Q3: Can I add new PDF circulars to the RAG knowledge base?
A3: Yes! Copy any `.pdf`, `.txt`, or `.md` file into `/data/rag_data/` and run:
    npm run rag:ingest
    The system extracts the text, computes hierarchical chunks, and generates 
    vector embeddings automatically.

Q4: What if I want to run the application completely offline without internet?
A4: NiveshRakshak was designed to run 100% offline out-of-the-box. The dense 
    vectorizer, BM25 matcher, RRF reranker, and multi-agents use local numerical 
    models and require zero external API keys or cloud connections.
